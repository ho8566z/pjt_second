① 개발 환경 변경
[개발 환경 변경] 로컬 MySQL·nginx 설정이 white-eyes-deploy 저장소로 옮겨졌습니다 (spring #236)

★ spring을 pull 하기 "전에" spring 폴더에서 한 번:
docker compose down -v
(pull 하면 spring의 docker-compose.yml이 없어져서 예전 MySQL을 못 지웁니다)

이후:


white-eyes-deploy를 spring·flask 옆에 clone (WSL 안 같은 폴더)https://github.com/white-eyes1/white-eyes-deploy
deploy에서 cp .env.example .env → 값 채우기(아래 값 사용)
MySQL만 띄우기: docker compose up -d mysql
spring .env를 새 .env.example에 맞게 고치기 (MYSQL_* 삭제, ADMIN_DB_PASSWORD·USER_DB_PASSWORD 추가)
앱 실행은 spring CLAUDE.md '명령' 참고
관리자 앱 먼저 띄운 뒤 deploy에서: docker compose run --rm --no-deps db-grants
사용자 앱은 이제 제한 계정(white_eyes_user)으로 뜹니다. 'command denied'가 나면 db-grants부터 돌려 보세요
새 표를 만드는 마이그레이션이 머지되면 db-grants를 다시 돌려야 합니다



참고


기존 로컬 DB 데이터는 옮겨지지 않습니다. 행정구역 적재·시연용 통계를 다시 돌려 주세요
Windows에 MySQL이 설치돼 있으면(3306 사용 중) deploy .env에 MYSQL_PORT=3307, spring .env의 DB_URL도 3307
시연용 통계 견본 위치가 admin/demo/로 바뀌었습니다 (spring #241)
